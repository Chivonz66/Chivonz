CHIVONZ Studio

Bu stüdyo sitesi — statik öncelikli, çok sayfalı ve GitHub Pages üzerinde yayında.

Yayında WEB HTML CSS JavaScript

Overview

Bu projeyi gördüğünüz site — CHIVONZ'un hizmetlerini tanıtan çok sayfalı bir stüdyo sitesi. Framework veya build katmanı yok: saf HTML, CSS ve birkaç küçük JavaScript dosyası.

Problem

Bir geliştirici portfolyosunun hem markayı profesyonelce yansıtması hem de bakımı kolay ve sıfır bağımlılıkla yayınlanabilir olması gerekiyordu. Bağımlılık ağırlıklı bir araç yığını bu hedefle çelişirdi.

Solution

Statik-first yaklaşım: her ana hizmet kendi sayfasına sahip, tasarım sistemi ortak CSS değişkenleriyle yönetiliyor, GitHub Pages üzerinde anında yayına çıkıyor.

  • 8 sayfadan oluşan çok sayfalı mimari
  • Ortak tasarım sistemi (CSS custom properties)
  • Page transition, reveal ve mikro-etkileşimler
  • 320–1920px arası duyarlı kompozisyon
  • reduced-motion ve erişilebilirlik desteği

Results

Site yayında ve çalışıyor. Sıfır harici runtime bağımlılığı, düşük gönderim boyutuna karşı optimizasyon yolu açık.
